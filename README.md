天氣查詢系統

這是一個使用 Python 撰寫的終端機應用程式，透過OpenWeatherMap API，讓使用者可以輸入城市名稱並取得即時天氣資訊。


* **即時查詢：** 輸入城市英文名稱，立即取得全球各城市的天氣狀況
* **氣象數據：** 顯示詳細溫度 (°C) 與濕度 (%)
* **錯誤處理：** 當輸入無效城市或網路連線失敗時，給予提示

* **Requests 套件** (處理 API 網路請求與 JSON 解析)
* **python-dotenv 套件** (管理環境變數與資安)
